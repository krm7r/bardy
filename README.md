# بردي — محرك البحث المصري

محرك بحث عربي (RTL) للمواقع والمصادر المصرية، مبني كموقع ثابت على **Cloudflare Pages** مع طبقة وسيطة (Pages Functions) تحمي خدمة البحث.

## المميزات
- تبويبات بحث: الويب، الإجابات (AI)، الصور، الفيديو، الأخبار، الأنشطة المحلية، الأحداث.
- فهم اللهجة المصرية وتصحيح الأخطاء الإملائية الشائعة (`tools/arabic-search-cases.json`).
- اقتراحات بحث (`suggestions.json`) وتصنيف (`taxonomy/`).
- تطبيق ويب قابل للتثبيت (PWA) ويعمل أوفلاين للصفحات الأساسية.
- **شريط جانبي موحّد** في كل الصفحات: الأقسام الرئيسية، الإعدادات، معلومات الموقع، وتاريخ اليوم (ميلادي وهجري).
- **خلفيات مصرية متغيرة تلقائيًا** (أهرامات، نيل، الكرنك، أبو الهول، عين حورس، أبو سمبل) بدون طبقة بيضاء فوقها، ويمكن إيقافها أو تثبيتها أو تغيير مدتها.
- **صفحة إذاعة مستقلة** (`/radio`) بخلفية مصرية متغيرة وأزرار مشاركة (واتساب، فيسبوك، تيليجرام، X، نسخ الرابط).
- **إذاعة القرآن الكريم** زرها العائم بدون لوحة: **ضغطة = تشغيل/إيقاف، ضغطة مطولة = فتح صفحة الإذاعة**، وقابل للسحب (يتذكر مكانه)، مع زر إظهار/إخفاء من الشريط الجانبي، وتستمر بعد التنقل بين الصفحات، ويمكن تشغيلها في نافذة منفصلة لا تتوقف أبدًا.
- **تبويب الأخبار بشكل مدونة**: خبر رئيسي كبير، أبرز الأخبار بجانبه، ثم باقي الأخبار.
- اختصار `/` للانتقال لمربع البحث، وزر لمسح سجل البحث.
- فلتر محتوى على مستوى الخادم + حد أقصى للطلبات + قبول الطلبات من الموقع نفسه فقط.

## الهيكل
| المسار | الوظيفة |
|---|---|
| `*.html` | صفحات الموقع |
| `assets/` | CSS وJS والصور |
| `functions/api/worker/[[path]].js` | الوسيط: التحقق من الطلب، الفلتر، تمرير البحث للخدمة |
| `sw.js`, `manifest.webmanifest` | الـPWA |
| `tools/` | أدوات اختبار وبناء (بحث عربي، اقتراحات، تصنيف) |

## الفهرسة (SEO)
الصفحات `web`/`ai`/`images`/`videos`/`news`/`local`/`events` عليها `noindex` عمدًا (نتائج بحث ديناميكية أو صفحات «قريبًا») وليست في `sitemap.xml`؛ الـsitemap فيه الصفحات القابلة للفهرسة فقط. لو أردت فهرسة تبويب منها: غيّر الـrobots فيه إلى `index,follow` ثم أضفه للـsitemap.

## الخلفيات: صور حقيقية محلية
الخلفيات صور حقيقية محفوظة داخل `assets/bg/photos/`، وقائمتها واعتماداتها في `assets/bg/backgrounds.json` و`assets/bg/CREDITS.md`. لا تعتمد الخلفيات على تنزيل صور من مواقع خارجية وقت التشغيل، وتُخزّن الصور محليًا ضمن ملفات الأوفلاين. لو تعذّر تحميل صورة يتخطاها الموقع تلقائيًا.

**إضافة/تحديث صور الخلفيات:** على جهازك (Node 18+ وإنترنت):
```
node tools/fetch-backgrounds.mjs            # صورة لكل موضوع (أهرامات، أبو الهول، الكرنك، أبو سمبل، النيل، الأقصر، فيلة)
node tools/fetch-backgrounds.mjs --per-theme=2
node tools/fetch-backgrounds.mjs --dry-run  # معاينة بدون تنزيل
```
السكربت يقبل فقط صور ويكيميديا كومنز بترخيص CC0 / ملكية عامة / CC BY / CC BY-SA (ويرفض NC وND)، أفقية وبدقة كافية، ويفضّل الصور المميزة، ثم يحفظها في `assets/bg/photos/` ويكتب اسم المصوّر والترخيص في `backgrounds.json` و`assets/bg/CREDITS.md` ويظهر اسم المصوّر في القائمة الجانبية. **لا تحذف الاعتمادات** (الترخيص يتطلبها). راجع الصور بعينك قبل النشر.

**الطريقة 2 — صورك الخاصة:** ضع صورة (JPG/WebP بعرض 1920 تقريبًا) في `assets/bg/photos/` وأضف سطرًا في `backgrounds.json`:
`{ "type": "photo", "src": "/assets/bg/photos/اسمها.jpg", "title": "العنوان", "credit": "اسم المصوّر", "license": "الترخيص" }`
(`credit`/`license`/`creditUrl` اختيارية لصورك أنت.)

الصور الحالية محفوظة محليًا بالفعل؛ تشغيل السكربت مرة أخرى يجلب صورًا مرخّصة ويحدّث القائمة والاعتمادات. راجع التغييرات قبل نشرها.

## ملاحظة عن الإذاعة
المتصفح يوقف أي صوت عند فتح صفحة جديدة في الموقع، لذلك يحاول بردي استئناف البث تلقائيًا في الصفحة التالية، وإن منعه المتصفح فيكفي ضغطة في أي مكان. للتشغيل المتواصل بلا أي انقطاع استخدم زر «نافذة منفصلة» (`radio.html`).

## التشغيل والنشر
1. ارفع المشروع على Cloudflare Pages (أو اربطه بمستودع GitHub).
2. أضف متغير البيئة `LEEG_URL` = رابط خدمة البحث الخلفية. **بدونه ترجع الواجهة خطأ 503.**
   داخل `leeg` أضف السر `EVENTS_API_URL` بقيمة رابط عامل الأحداث من مدير الأسرار،
   حتى يعمل تبويب الأحداث عبر المسار `/events`. لا تضع الرابط في الكود أو GitHub.
3. الدومين الافتراضي `https://bardy.pages.dev` — الوسيط يقبل أيضًا أي دومين ينشر عليه الموقع نفسه.

## ملاحظة عن فلتر المحتوى
المصطلحات المحظورة مخزّنة كقيم hash لكلمات كاملة (وليست نصوصًا)، والمطابقة بالكلمة الكاملة بعد تطبيع الحروف العربية (الهمزات، التاء المربوطة، التشكيل) وإزالة "ال" والسوابق الشائعة، لتجنّب حجب كلمات بريئة مثل أسماء المدن.

## الذكاء الاصطناعي والبحث (ملخص)
- الويب والصور: حتى **350 حرفًا** (فوقها رسالة واضحة). إجابات الذكاء الاصطناعي: بلا قيد عمليًا.
- مصادر الإجابة تظهر كروابط (chips) باسم الموقع، وأرقامها ثابتة مع مصادر الإجابة.
- الصور المكسورة تُحذف من الشبكة تلقائيًا، وتُحمَّل الصور بدون Referer لتفادي منع الـhotlink.
- تفاصيل الـ Workers في `CHANGES_AR.md` ضمن حزمة الـ Workers.
